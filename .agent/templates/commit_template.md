# コミットメッセージ テンプレート

## ブランチ名

> ブランチ名は `<種類>/#<issue番号>-<summary>`。種類と issue・PR タイトルの prefix の対応は `issue_template.md` の「タイトル・ブランチ名の規定」を参照。

## ブランチでの作業内容の要約

### "コミットメッセージ1"

```
git add ファイル名1 ファイル名2...
```

```
git commit -m "コミットメッセージ"
```

### "コミットメッセージ2"

```
- git add ファイル名 ファイル名2...
```

```
- git commit -m "コミットメッセージ"
```
